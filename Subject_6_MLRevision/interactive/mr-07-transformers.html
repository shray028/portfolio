Attention & transformers

Every LLM, embedding model and re-ranker you will discuss is a transformer. Interviewers expect you to explain self-attention from Q, K and V, justify the √d scaling, say why positions must be injected, compare encoder and decoder models, and reason about the KV cache that dominates LLM serving memory.

Concept

Each token asks a question (Q), every token offers a key (K) and a value (V) Must-know

\( \text{Attention}(Q,K,V)=\text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}+M\right)V \)

Q, K and V are learned linear projections of the token embeddings. A token's output is a weighted average of all values, weighted by how well its query matches each key — so "it" can pull in information from "animal" in one step, however far apart they are. Multi-head attention runs several smaller attentions in parallel so different heads can track different relations (syntax, coreference, position). The mask M adds −∞ to forbidden positions (future tokens in a decoder).

Concept

Attention is order-blind — positions must be added

Self-attention treats its input as a set: shuffle the tokens and each output is just shuffled the same way. So "dog bites man" and "man bites dog" would look identical. The original transformer adds sinusoidal encodings — each dimension pair is a sine/cosine of a different wavelength, so every position gets a unique pattern and relative offsets are linear functions. BERT/GPT-2 learn absolute position embeddings. Modern LLMs use RoPE (rotate Q and K by a position-dependent angle so their dot product depends on relative distance) or ALiBi (a distance penalty on scores), which extend better to longer contexts.

\( PE_{(pos,2i)}=\sin\!\big(pos/10000^{2i/d}\big),\qquad PE_{(pos,2i+1)}=\cos\!\big(pos/10000^{2i/d}\big) \)

Concept
Encoder-only

BERT, RoBERTa, embedding models

Bidirectional attention: every token sees every other token. Pre-trained with masked-language modelling. Best for understanding: classification, NER, embeddings for search, cross-encoder re-rankers.

Decoder-only

GPT, Llama, Claude-style LLMs

Causal attention: each token sees only the past. Pre-trained with next-token prediction, which scales simply and makes every task text generation. The default for chat and agents.

Encoder–decoder

T5, BART, original Transformer

Encoder reads the input bidirectionally; decoder generates causally and uses cross-attention to the encoder output. Natural for input→output tasks: translation, summarisation.

Concept

Generation recomputes nothing it has seen: it caches K and V Must-know

Autoregressive decoding produces one token at a time. Without a cache, step t would recompute keys and values for all t previous tokens — quadratic work. The KV cache stores every layer's K and V so each new token only computes its own, making decoding memory-bandwidth bound. The cache grows linearly with sequence length and batch size and often exceeds the weights. GQA (grouped-query) and MQA (multi-query) let many query heads share fewer KV heads, shrinking the cache; PagedAttention (vLLM) avoids fragmentation; quantising the cache (FP8) halves it again.

\( \text{KV bytes} = 2 \times L \times n_{kv} \times d_{head} \times \text{seq} \times \text{batch} \times \text{bytes/value} \)
