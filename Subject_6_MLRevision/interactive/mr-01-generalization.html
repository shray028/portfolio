MODULE 01 · FUNDAMENTALS

Bias, variance & generalization

The single most-asked ML interview question, made visible. Fit the same model to many noisy training sets: how far the average fit is from the truth is bias; how much the fits disagree with each other is variance. Then control it with regularization, diagnose it with learning curves, and measure it honestly with cross-validation.

Concept

Expected error = bias² + variance + irreducible noise Must-know

Bias is error from wrong assumptions — the model is too simple to capture the pattern, so even the average of many fits misses (underfitting: high train and test error). Variance is error from sensitivity to the particular training sample — the model fits the noise, so retraining on new data gives a very different fit (overfitting: low train error, high test error). Increasing complexity trades one for the other; the sweet spot minimises their sum. Noise (σ²) is the floor no model can beat.

\( \mathbb{E}\big[(y-\hat f(x))^2\big] = \underbrace{\big(f(x)-\mathbb{E}[\hat f(x)]\big)^2}_{\text{bias}^2} + \underbrace{\mathbb{E}\big[(\hat f(x)-\mathbb{E}[\hat f(x)])^2\big]}_{\text{variance}} + \sigma^2 \)

Concept

L2 shrinks, L1 selects Must-know

Regularization adds a penalty on weight size so the model prefers simpler fits: more bias, much less variance. L2 (ridge) adds \(\lambda\sum w_j^2\): every weight shrinks smoothly towards zero but rarely hits it, and correlated features share the weight. L1 (lasso) adds \(\lambda\sum |w_j|\): weights hit exactly zero, so it doubles as feature selection. Elastic net mixes both.

Why L1 gives zeros: the geometry

The loss contours (amber) first touch the L1 diamond at a corner, where one weight is exactly zero. The L2 circle has no corners.

Concept

Learning curves tell you which problem you have Must-know

Plot training and validation error against training-set size. High bias: both curves plateau close together at a high error — more data won't help; add capacity or features. High variance: a large gap between a low training error and a higher validation error that is still falling — more data, regularization or a simpler model will help. Pick the scenario and read the diagnosis.

Concept

Your split must mimic production Must-know

Use train to fit, validation (or cross-validation) to choose models and hyperparameters, and touch the test set once at the end. k-fold CV averages over k train/validation splits for a lower-variance estimate. The split must match how the model meets new data: stratified for imbalanced classes, time-based when predicting the future, grouped when the same user or patient appears many times. Anything learned from validation data before the split — scaling, imputation, target encoding — is leakage.
