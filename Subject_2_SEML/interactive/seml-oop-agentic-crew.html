Profiling toolsFind the bottleneck before optimising

    

      
cProfile
Deterministic profiler for the whole program: number of calls, total time inside each function (tottime) and including sub-calls (cumtime). Answers which function is slow.

      
line_profiler
Decorate a function with @profile and run kernprof -l -v to see time per line — answers which line inside the slow function is the problem.

      
memory_profiler
Line-by-line memory usage and increments (mprof for plots). Finds leaks, e.g. an agent that appends every prompt to _memory forever.
