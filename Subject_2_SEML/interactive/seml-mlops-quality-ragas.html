Automated retraining loop

Monitoring compares live data (and, once labels arrive, live accuracy) with the training baseline. Crossing a threshold triggers retraining; the new model must pass validation before the registry promotes it.

Covariate / data drift

P(X) changes — the inputs look different from training (e.g. a new customer segment, a pandemic wave changing behaviour). Detectable without labels using PSI, KS-test or KL divergence.

Concept drift

P(y | X) changes — the same inputs now mean something different (e.g. fraud patterns evolve). Inputs can look identical, so you need ground-truth labels and performance monitoring to catch it.
