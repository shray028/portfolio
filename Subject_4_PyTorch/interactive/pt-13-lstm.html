LSTMs & a next-word predictor

Plain RNNs forget: their gradients fade after a dozen steps. LSTMs add a gated memory cell that can carry information — and gradients — across long sequences. Then you'll turn a paragraph into training data and generate text one word at a time.

Concept

Gradients multiply through time Must-know

To learn that the word 30 steps ago mattered, the gradient must flow back through 30 copies of the recurrent cell, getting multiplied by roughly the same factor each time. A factor below 1 shrinks it exponentially (vanishing); above 1 it blows up (exploding). The LSTM's cell state is updated additively, cₜ = fₜ·cₜ₋₁ + iₜ·g̃ₜ, so the gradient along it is scaled only by the forget gate — which the network can learn to keep near 1.

Three gates control one memory cell Must-know

fₜ = σ(·)
Forget gate — how much of the old memory cₜ₋₁ to keep (1 = keep all).
iₜ = σ(·)
Input gate — how much of the new candidate to write.
g̃ₜ = tanh(·)
Candidate — the new information, in [−1, 1].
oₜ = σ(·)
Output gate — how much of the memory to reveal as hₜ.
cₜ, hₜ
cₜ = fₜ⊙cₜ₋₁ + iₜ⊙g̃ₜ   hₜ = oₜ⊙tanh(cₜ)

Each gate is its own small layer over [hₜ₋₁, xₜ], which is why an LSTM has 4× the parameters of a plain RNN of the same size.

Concept

Every prefix is a training example Must-know

For each sentence, every prefix predicts the word that follows it. Left-pad the prefixes to a common length so the most recent words sit at the end — exactly where the LSTM's last time step reads them. The target is the next word's id, so this is a classification problem with vocab_size classes.

Concept

Predict, append, repeat

The model outputs logits over the whole vocabulary for the next word. Pick one (greedily or by sampling), append it to the input, and run again. Temperature divides the logits before softmax: low T sharpens the distribution (safe, repetitive), high T flattens it (creative, error-prone).

The demo below uses a small count-based (bigram) model trained instantly in your browser on the paragraph shown, so you can see decoding behaviour live. The PyTorch LSTM in the code block learns the same kind of distribution, conditioned on the whole prefix rather than one word.
