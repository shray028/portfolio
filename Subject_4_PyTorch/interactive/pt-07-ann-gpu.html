Concept

Image → vector → hidden layers → 10 logits

Fashion-MNIST has 60,000 training and 10,000 test images of 10 clothing classes, each a 28×28 grayscale image. An MLP doesn't understand 2-D structure, so each image is flattened into 784 numbers (scaled to 0–1). Two hidden layers with ReLU learn features; the last layer outputs 10 logits, one per class. No softmax — CrossEntropyLoss handles it. Must-know

Concept

Three lines move training to the GPU Must-know

  1. Pick the device once: device = "cuda" if torch.cuda.is_available() else "cpu" (or "mps" on Apple silicon).
  2. Move the model once: model.to(device) — in place for modules.
  3. Move every batch inside the loop: xb, yb = xb.to(device), yb.to(device) — tensors return a new copy, so reassign.

GPUs win on large, parallel work: big batches, big layers, convolutions. Copying data across PCIe and launching kernels has overhead, so tiny models can even be slower on a GPU.
