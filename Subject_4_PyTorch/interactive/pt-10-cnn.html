Convolutional neural networks

A CNN slides small learned filters over an image, so it sees local patterns — edges, corners, textures — with a tiny number of shared weights. Get the convolution, pooling and shape arithmetic right and building CNNs becomes mechanical.

Concept

A filter slides, multiplies and sums Must-know

At each position the 3×3 kernel is multiplied element-wise with the patch under it and summed (plus a bias) to produce one output value. The kernel's weights are learned — the network discovers its own edge and texture detectors. Padding adds a border of zeros so edges get covered and size can be preserved; stride is the step between positions.

out = ⌊(N − K + 2P) / S⌋ + 1  —  and a Conv2d has out_c × (in_c × K × K + 1) parameters, whatever the image size.

Concept

Downsample by summarising windows

nn.MaxPool2d(2) keeps the largest value in each 2×2 window (stride defaults to the kernel size), halving height and width. It has no parameters, reduces compute for later layers, and makes the network a little tolerant to small shifts. Average pooling takes the mean instead; nn.AdaptiveAvgPool2d((1, 1)) pools any size down to 1×1 per channel ("global average pooling").

Concept

Track (C, H, W) layer by layer Must-know

Convolutions change C to out_channels and shrink or keep H×W according to the formula; pooling divides H×W; activations and BatchNorm keep the shape. Before the classifier, nn.Flatten() turns (C, H, W) into C·H·W features — that number must be the in_features of the first Linear layer, and getting it wrong is the classic "mat1 and mat2 shapes cannot be multiplied" error.

Concept

Feature extractor + classifier

The standard layout: blocks of Conv → BatchNorm → ReLU → MaxPool extract increasingly abstract features while halving resolution and growing channels (32 → 64 → 128). Then Flatten → Linear → ReLU → Dropout → Linear classifies. Everything else — DataLoader, loop, GPU, evaluation — is identical to the ANN in module 07.
