MODULE 03 · FOUNDATIONS

Autograd — gradients for free

Training is "nudge every weight downhill". To know which way is downhill you need ∂loss/∂weight for millions of weights. Autograd records your forward pass as a graph and runs the chain rule backwards through it — here you can watch it happen node by node.

The chain rule, automated Must-know

For one neuron with a sigmoid and binary cross-entropy, you can still derive the gradients by hand:

z = w·x + b → ŷ = σ(z) → L = −[y·log ŷ + (1−y)·log(1−ŷ)]

∂L/∂w = ∂L/∂ŷ · ∂ŷ/∂z · ∂z/∂w, which simplifies to (ŷ − y)·x, and ∂L/∂b = ŷ − y. Now imagine doing that for a 50-layer network. Autograd does exactly this bookkeeping for any composition of differentiable operations: set requires_grad=True, compute the loss, call loss.backward(), read .grad.

Forward builds the graph, backward walks it in reverse

Each operation on a tracked tensor creates a node that remembers its inputs and how to compute its local derivative. The result tensor points to that node through grad_fn. backward() starts at the output with gradient 1 and, at each node, multiplies the incoming gradient by the local derivative and passes it on. Where branches meet, gradients add.

Only leaf tensors you created with requires_grad=True keep their .grad. Intermediate results don't, unless you call .retain_grad(). Must-know

Concept

backward() adds, it does not overwrite Must-know

Every call to backward() adds the new gradient into .grad. That's useful when you deliberately sum gradients over several mini-batches, but in a normal loop it means stale gradients pile up. That's why every training step begins (or ends) with optimizer.zero_grad().

Turning tracking off Must-know

with torch.no_grad():
Nothing inside is recorded. Use for validation, inference and manual weight updates — saves memory and time.
torch.inference_mode()
Stricter, slightly faster no_grad for pure inference.
t.detach()
Same data, but cut from the graph. Use to log values, feed a target network, or stop gradients flowing into part of a model.
p.requires_grad_(False)
Stops tracking a parameter permanently — how you freeze layers.
