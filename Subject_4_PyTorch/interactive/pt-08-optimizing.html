MODULE 08 · BUILDING NETWORKS

Optimizing the network — beat overfitting

A network with enough parameters can memorise the training set. These four tools make it generalise instead — and each has a train-time vs eval-time subtlety that interviewers love to ask about.

4 sectionsEarly stopping · dropout · batch norm · weight decay
Concept

The gap between training and validation loss Must-know

Early in training both losses fall together. When the model starts fitting noise specific to the training set, training loss keeps falling while validation loss turns upward. That turning point is the best model you will get from this run. Early stopping watches validation loss, keeps the best weights, and stops after patience epochs without improvement.

Concept

Randomly switch off units during training Must-know

On every forward pass in train() mode, nn.Dropout(p) zeroes each activation with probability p and multiplies survivors by 1/(1−p). Units can't co-adapt, so the network learns redundant, robust features — like training many thinned networks and averaging them. In eval() mode dropout does nothing; thanks to the scaling at train time, the expected activation is the same in both modes.

Concept

Normalise each feature over the batch, then rescale Must-know

For a feature with batch mean μB and variance σ²B: x̂ = (x − μB) / √(σ²B + ε), then y = γ·x̂ + β with learnable γ (scale) and β (shift). Keeping every layer's inputs centred and scaled lets you use larger learning rates and makes training less sensitive to initialisation. In training, μ and σ come from the batch and a running average is updated; in evaluation, the running averages are used.

Concept

Penalise large weights Must-know

L2 regularisation adds λ·Σw² to the loss, which pushes every weight toward zero each step. Big weights let a model make sharp, wiggly predictions that chase noise; keeping them small yields smoother functions. In PyTorch you pass weight_decay=λ to the optimizer. With Adam, prefer AdamW, which applies the decay directly to the weights.

λ (weight decay strength)

With λ ≈ 0 the curve threads through every training point and swings wildly between them (overfitting). Increase λ and the weights shrink — the curve smooths toward the true sine. Too much λ underfits.
