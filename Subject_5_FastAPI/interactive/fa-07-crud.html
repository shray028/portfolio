A Pydantic parameter = the JSON body Must-know

When a parameter is annotated with a BaseModel subclass, FastAPI reads the JSON body, validates it and hands you the object. Invalid input → automatic 422 with exact error locations; your function never runs on bad data.

Then: load the store, refuse duplicates (409, or 400 as in the course), convert the object with model_dump(exclude={"id"}) — which includes the computed bmi and verdict — put it under the id, save, return 201.

The most important logic in the course Must-know

The client sends only what changed, e.g. {"weight": 60}. So PatientUpdate mirrors Patient with every field Optional[...] = None and no id (it comes from the path). Then: load → dump the patch with exclude_unset=True → merge → rebuild through Patient(**...) to re-validate and recompute BMI/verdict → dump back → save.
