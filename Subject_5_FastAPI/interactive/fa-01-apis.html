FastAPI = type hints → HTTP endpoints Must-know

FastAPI is a thin, type-hint-driven layer that turns Python functions into HTTP endpoints. It borrows its speed from Starlette and Uvicorn, and its correctness from Pydantic.

Concept

An API is a contract Must-know

An API lets one piece of software ask another for data or an action without knowing how the other works inside. A web API exposes that contract over HTTP: send a request to a URL, get back (usually) JSON.

The restaurant analogy: you (the client) never walk into the kitchen (server + database). You talk to the waiter (the API), who has a fixed menu (the endpoints) and takes orders in a fixed format (the request schema).

A model in a notebook helps nobody

A trained model lives in a notebook or a .pkl file. Wrapping it in an API turns it into a service: any website, mobile app or backend sends features and receives a prediction. This is the end state of the course — click the parts of the diagram.
