Concept

Middleware wraps every request and response, like an onion

Each layer sees the request on the way in, calls await call_next(request) to run everything inside it, then sees the response on the way out. That's where timing, logging, request IDs and CORS live. The last middleware added is the outermost. Exception handlers turn an exception raised inside into a proper response.

Concept

CORS is a browser rule Must-know

Browsers block JavaScript on one origin (scheme + host + port) from reading responses from another origin unless the server answers with Access-Control-Allow-Origin. Non-simple requests (JSON body, custom headers, PUT/DELETE) first send a preflight OPTIONS. Streamlit (server-side Python), curl and Postman never hit CORS. Fix it with CORSMiddleware and an explicit list of origins.

Concept

Respond first, do the slow side job after

background_tasks.add_task(fn, *args) runs fn in the same process after the response is sent. Good for small fire-and-forget work: a confirmation email, a log line, a cache refresh. If the process dies the task is lost and there are no retries, so heavy or must-not-lose jobs belong in a queue (Celery, RQ, SQS).

Concept

TestClient calls your app in-process, no server needed Must-know

Write tests with pytest and TestClient(app); use with TestClient(app) as client: so lifespan runs. Swap slow or external pieces with app.dependency_overrides. Most importantly, test write endpoints with a round trip: create, then read it back. The course's /create returned 201 without saving anything; one round-trip test catches it.

Concept

API key for services, OAuth2 + JWT for users

An API key in a header is the simplest option for service-to-service calls: a dependency reads it and raises 401. For user logins, POST /token checks the password (hashed with bcrypt or argon2, never plaintext) and returns a signed JWT with an expiry. The client sends Authorization: Bearer <jwt>; a Depends(get_current_user) verifies the signature and decodes the user. The server stores no session: the token is self-contained.
