Dependencies, lifespan & routers

The three tools that turn a single-file demo into a maintainable service: Depends to share logic (auth, DB sessions, pagination, the model), lifespan to load and release resources once, and APIRouter to split routes into files.

Concept

A dependency is a function FastAPI calls for you and injects Must-know

FastAPI resolves the dependency's own parameters (query, header, other dependencies) and documents them; a yield dependency gives setup and teardown; results are cached within one request; and in tests app.dependency_overrides[get_db] = fake_db swaps it without touching the endpoint.

Concept

One router per resource, assembled in main.py

APIRouter is a mini-app: routes, prefix, tags and dependencies. app.include_router(router, prefix="/v1") stacks another prefix on top, which is how API versioning is usually done. The final path is include prefix + router prefix + route path.
